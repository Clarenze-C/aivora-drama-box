- Their invariant (ordered, non-overlapping, `0 <= start < end`) is exactly what the clamp satisfies.
- Matching works by interval intersection.
- `validate_binding` reads only `end_ms`.
- The `end <= start` guard rules out empty windows.

A shot that sits entirely inside a crossfade fails closed and returns None. The reader is not wired into the pilot.
