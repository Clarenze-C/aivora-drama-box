# T031 Pika H3 Flex preparation artifacts

Prepared 6 November 2026 for [the benchmark packet](../T031-benchmark-packet.md).
Everything here is preparation or source evidence. No sample has run.

- `shots.csv`: eight original proposed Thai test scripts and required observations.
- `trials.csv`: 24 sample identities and seeds; three screening samples are part
  of that total, not additional attempts.
- `results-template.csv`: one unmeasured row per sample. UNKNOWN means unchecked;
  blank costs are not zero, and no output hash is invented.
- `source-pins.json`: immutable public source/model revisions, published weight
  checksums/sizes, license hashes and hashes of the saved upstream graphs.
- `upstream-pika-h3-flex-{ref2va,fl2va,t2v}.json`: byte-preserved official ComfyUI
  UI templates. Only Ref2VA is the first proposed experiment. These are not
  runnable Drama Box API payloads or runtime-tested graphs.
- `canary-evidence-index.json`: hashes and tracked/untracked status of local prior
  evidence inspected for [the canary close-out](../T031-canary-closeout.md).

Downloaded content was limited to public metadata and small workflow JSON files.
No model weights, example media, credentials, private account data or source code
packages were downloaded. Retain vendor workflow bytes to preserve their hashes;
derive any executable graph as a separate versioned artifact.

The proposed $8 envelope is unsigned and covers one configuration. Runtime image,
schema/control attestation, actual inputs, A40 compatibility, rights/access,
evaluator coverage, budget reconciliation and a 24-sample execution path remain
preconditions for paid-run sign-off. Native voice is part of the H3 Flex route;
separate TTS is not the default.
