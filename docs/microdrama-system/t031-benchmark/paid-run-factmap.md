## 10. Gaps (code expects it; nothing in the repo provides it)

1. **No live `/object_info` capture tool.** `BenchmarkSeal.raw_object_info` and `schema_attestation_source: "INDEPENDENT_RUNTIME_CAPTURE"` are operator-authored; no command captures the runtime schema on a GPU pod after weights are present (only the CPU smoke exists, and its hash is machine-denied for live seals). Search: `raw_object_info` producers across src/tests/runbooks → only validator/consumer sites.
2. **No example/generator documents for the benchmark path.** No `BenchmarkPlan/BenchmarkSeal/BenchmarkAuthorization/AcquisitionQuote` JSON fixture or authoring tool; tests construct models in Python (`X/unit/pipeline/test_benchmark_authorization.py`); the runbook example JSON is the *canary* schema, not the benchmark one.
3. **No CLI for registry writes on the paid path.** `CredentialStore.register`, `RightsRegistry.record`, `PresetRegistry.record`, asset registration are library APIs; `tools/canary_db.py` seeds only a fixture rights route + fixture preset. The real preset row, real rights records and asset rows must be created by bespoke Python.
4. **Weights provisioning is unhooked.** `D/provision.py --download` is documented but invoked by no code; the paid path never triggers or verifies weight presence beyond the runtime schema hash (empty model enums in the weight-free image are what the live capture must clear).
5. **Cold-start / sampler timing capture: NOT FOUND** (`cold_start`, `sampler_ms` have no writers in `microdrama/src`), though `results-template.csv` requires `cold_start_ms`/`full_job_ms`/`sampler_ms`.
6. **No benchmark-side `record_billing_evidence` CLI** — it runs only from the billing-ingest path (`runpod_billing.py:117`); manual correction/entry is Python-only.
7. **Export → results-template.csv mapping is manual**; export omits the template's quality/coverage columns and reports `cost_micro_usd: null` per sample.

**Untracked-in-branch context** (for the orchestrator): this worktree lacks the packet docs; they live in the main checkout `docs/microdrama-system/` (`T031-benchmark-packet.md`, `T031-authorization-packet.md` — the latter is the historical *canary* packet with the run-14 CLI examples and sign-off table).
