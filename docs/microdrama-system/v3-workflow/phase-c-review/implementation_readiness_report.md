### BLOCKER

1. The pick-kind to reference-version mapping is undefined, and it is the address space of the whole phase. Scope: §2 migration C-1 (line 98), §4 "Candidates" (lines 161-163), §8 lock transaction step 3 (lines 326-327).
   - `reference_versions.ref_kind` is enforced as exactly FACE/VOICE/WARDROBE/LOCATION/STYLE, both by a SQL CHECK (0002:158) and by the frozen Python enum in microdrama/src/microdrama/contracts/enums.py:312; `identity_lock_assets.asset_kind` has the same five-value CHECK (0002:275). PROP and MUSIC_LIB/SFX_LIB have no plausible existing kind at all, so the §8 assertion cannot be fulfilled as written without either a contract change or a mapping the spec does not contain.
