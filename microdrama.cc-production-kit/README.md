# Making the Show — AI Microdrama Production Kit

Source: https://microdrama.cc/en/

This kit contains the prompts, JSON Schemas and worksheets from *Making the Show: The AI
Microdrama Production System* that transfer most directly into a project.

Start with a single pilot episode: establish the project, the characters and an episode pack
first, then bring in shot, continuity, generation, audio, editing, QC and release structures.
A schema validating is not the same as creative, legal, financial or platform compliance
judgment.

Contents:

- `prompts/`: showrunner, story architect, script room, storyboard director and QC agent.
- `schemas/`: project, episode, shot, asset, continuity, generation, audio, edit, QC, rights,
  metrics, task and release data structures.
- `worksheets/`: project greenlight, episode pack, asset and continuity, agent protocols,
  master acceptance and incident runbooks.
- `CHECKSUMS.txt`: SHA-256 checksums for the files in this package.

Copy it into your own project space before use, and adapt it to your team's responsibilities,
tool capabilities, territory rules and rights requirements.
