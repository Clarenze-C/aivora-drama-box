- Acceptance evidence (tests/integration/persistence/):

    (rows, asset descriptors, hashes and stored bytes survive; re-migrate is a no-op);
  - changed applied migration refused; 3 concurrent migrators apply each version once;
  - duplicate semantic jobs and duplicate SPEC publication-slot tuples rejected;

    media/policy/scope, and a DB trigger refuses approvals without a live human owner session
    (revoked/expired/other-owner/inactive/missing) — mutation-checked: dropping the trigger
    lets a revoked-session approval through, so the test depends on it;
  - budget backstop CHECK (outstanding+accrued+settled ≤ cap + recorded overrun; overrun forces
    paid_dispatch_blocked; cap immutable and ≤ US$10); receipt dedupe; fake/measured labelling;
  - single live GPU lease (pilot) and EXCLUDE constraint so a pod interval is billed once;
  - immutable Pass A observations; findings cannot be PASS with unsampled coverage; membership
    catalog cannot sell unapproved media or carry token links; series preferences need scope.
- External effects: none. Isolated ephemeral PostgreSQL only.
- Limits: DB triggers are defense in depth, not a security boundary against a principal with
  raw SQL access; per-role GRANTs are a deployment/live-readiness item. S3 adapter not built.
