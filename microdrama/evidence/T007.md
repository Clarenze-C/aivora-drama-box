# T007 — Deterministic fake-provider/media fixture harness

- Contract version: built against 1.0.0 (compatible with 1.1.0; additive change only).
- Paths: `src/microdrama/testing/{fakes/,media.py,network_guard.py}`,
  `tests/unit/testing_harness/`, `tests/contract/fakes/` (worker, Validator lane). Integrator
  wiring: `tests/conftest.py` installs the network guard for **every** test (autouse) and adds
  shared `fixture_truth` / `defect_suite` fixtures.
- Commands (orchestrator rerun): `pytest tests/unit/testing_harness tests/contract/fakes` →
  175 passed; full suite with the global guard → see ledger evidence line.
- Acceptance evidence:
  - strict offline mode: `block_network`/`install` refuse non-loopback connects, DNS lookups and
    egress through a configured proxy (the sandbox proxy is on loopback; the guard refuses it);
    `build_fake_providers` raises `EffectDenied` outside OFFLINE_MOCK; a full scripted run passes
    with loopback blocked too;
  - provenance sweep drives every scenario of every fake: all receipts `FAKE_SYNTHETIC` /
    `SYNTHETIC_FAKE`, all URLs `https://*.invalid`; media fixtures are `ORIGINAL_FIXTURE`,
    synthetic, `measured_quality=False`;
  - complete vs partial outputs: Comfy `EXECUTED_WITHOUT_OUTPUT`, generation `PARTIAL_OUTPUT`
    (complete=False, hash mismatch), truncated MP4 fails decode/probe while complete clips pass;
  - fault scenarios: ambiguous submit/create reconciled by client token, not-accepted → NOT_FOUND,
    duplicate tokens never double-bill, late billing ACCRUAL→ADJUSTMENT, 429/denied/expired
    token/unsupported disclosure, foreign pods recorded if touched, UI-format Comfy graph and
    unknown node classes refused without installing anything;
  - ASR/review report only registered fixture truth (never script text); unknown media →
    UNAVAILABLE coverage; seeded defects (wrong amount/speaker, identity swap, missing audio,
    silence, black, freeze, bad caption, out-of-bounds cue, wrong CTA, truncated) each produce
    their expected finding; black/freeze/silence are real and detected by ffmpeg filters;
  - replay: two fresh runs of the same scripted scenario produce identical ids/bytes/receipts.
- External effects: none. ffmpeg/ffprobe only on tmp paths; no media binaries committed.
- Limits (honest): fixture speech/identity live in a truth registry keyed by sha256 (tone audio
  cannot carry Thai speech); fake compare is a deterministic stand-in, not a quality claim; the
  guard sees Python-level sockets only (not subprocesses/C resolvers).
