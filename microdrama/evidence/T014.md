- Open items (honest):
  - `PRESET_TEMPLATES` maps only two preset ids. A CONTROL-class preset
    (`fake-control-baseline`, recorded in the offline catalog) has no mapping, so a
    QUALITY→CONTROL promotion currently ends in a typed `NoCompatiblePreset` instead
    of dispatching. Handoff proposal below.
  - Ranking compares presets only within the shot's allowed tier classes; a "cheap
    fast preset beats expensive quality preset for an emotional shot" scenario is
    intentionally impossible (TIER_POLICY fires first) — that ordering is by design,
    not an oversight.
  - `PresetMeasurements` has no field for cold/warm *sample variance*; the receipt
    keeps per-sample values, but the stored preset record keeps only the two summary
    figures the frozen contract defines. Variance would be a contract proposal.
  - `critical_quality_pass_bp` for a benchmarked preset is recorded as the minimum
    class acceptance (conservative offline proxy); T031's real benchmark should
    record a measured critical-quality pass rate instead.
