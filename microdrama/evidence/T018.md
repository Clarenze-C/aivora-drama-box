- Two separate calls, one seam boundary: Pass A dispatches through T017's
  `MediaObserver.observe(asset_id, asset_sha256, media_path, duration_ms)` protocol
  (blind); Pass B dispatches through the new `MediaComparator.compare(report, intent,
  …)` protocol (given intended answers) — the frozen report is the only thing that
  crosses from A to B. All findings are typed `QAFinding`s with
  `source_pass=PASS_B_COMPARISON` (T017 kernel findings reused by import are
  restamped; finding ids stay deterministic through `build_finding`), unknowns stay
  UNKNOWN, and every persisted row carries `observation_id` = the frozen report.
- Idempotency/determinism: Pass A request id = uuid5 over (episode, media sha16,
  question fingerprint) — no script component; report id = uuid5 over the request id;
  an identical request replays the frozen row without re-dispatch or charge. Pass B
  run key = canonical hash of (episode, report id+sha, script sha, canon version+sha,
  lock id, acceptance criteria, config fingerprint with floats scaled, lane
  `qa.comparison`); identical comparisons replay from persisted findings; media or
  script or canon or lock changes mint a new cycle, never overwrite
  (`test_identical_comparison_replays_without_new_rows`,
  `test_unspoken_reveal_passes_and_canon_binds_the_run`,
  `test_replay_returns_the_stored_report_without_a_second_call`).
