## Core truth: an ELIGIBLE route

TikTok publishing is only unattended through the documented Content Posting API
direct-post route of an audited app/provider holding the `video.publish` grant. The
lane encodes two provider routes:

- `tiktok-direct-post` (`post_mode=direct_post`) — fully unattended; the service's
  slot flow runs on it end to end offline.
- `tiktok-inbox-upload` (`post_mode=inbox_upload`) — the video lands in the user's
  inbox/drafts and a human must act. **Never mislabeled unattended**: its capability
  record marks `UPLOAD_FULL_VIDEO`/`UPLOAD_SHORT` UNSUPPORTED (so the service holds
  such slots with `CAPABILITY_UNAVAILABLE` before any adapter call —
  `test_service_holds_an_inbox_route_slot_before_any_adapter_call`,
  `test_inbox_capability_never_advertises_unattended_uploads`,
  `test_inbox_route_refuses_unattended_submit`, and the contract pin
  `test_inbox_route_slot_is_held_never_published_unattended`), and a direct adapter
  submit is a typed non-transient `INBOX_REQUIRES_HUMAN` failure that creates
  nothing.

## Implementation limits and honest unknowns

- **Readback truth**: whether the AIGC label's visibility is readable through any
  documented endpoint is UNKNOWN (capability says so). Offline, the readback echoes
  the declaration this process made at init (a fixture memory keyed by publish id,
  re-associated at reconcile for timeout-created posts); live disclosure-visibility
  verification waits for T032.
- **Fail-code literals**: only `VIDEO_REFUSED`, `SIZE_TOO_LARGE`,
  `FORMAT_UNSUPPORTED` are kept verbatim; any other code the platform may return
  collapses to `PUBLISH_FAILED` rather than leaking an untyped string.
- **Reconcile by token**: `find_publish_id` is the offline fixture's token map; the
  documented API reconciles by publish_id, so the live adapter (T032) must persist
  the init-returned publish_id durably before considering reconciliation.
- **Duration measurement**: offline duration comes from a deterministic sha-keyed
  probe seeded by the test world (mirrors the registered MediaInfo); the live
  adapter must probe the actual file.
- **Chunking**: the documented 4–64 MiB chunk window is honored (fixture streams the
  4 MiB minimum); upload URLs are fixture `*.invalid` stand-ins.
- **Doc drift**: the evidence refs point at the canonical developers.tiktok.com
  content-posting pages as-of 2026-10; exact slugs/values may have drifted since —
  they were not re-verifiable in this offline build.
