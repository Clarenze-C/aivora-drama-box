## API notes for the next session (learned the hard way)

- SQL placeholders: only `%s` allowed; escape LIKE wildcards as `%%`.
- `BudgetReservationRequest` ignores unexpected kwargs silently — ruff F821 is
  what caught a stray `world=` kwarg; keep request builders kwarg-clean.
- Principal kinds: SCHEDULER / SERVICE_WORKER / RUNTIME_MODEL (needs
  `runtime_role=`) / PROVIDER_WEBHOOK; HUMAN_OWNER without session_id cannot be
  constructed at all.
- `ensure_pod` performs client-token reconciliation INTERNALLY (one call adopts
  an ambiguously-created pod); the janitor's `stopped_pods` list only carries
  provider-orphans — lease-expiry stops land in `lease_outcomes`.
- Composed QA needs `build_pipeline_world(..., truth=fixture_truth)` so the
  observer reads the session defect-suite registry (`qa_world` fixture, done).
- `qa_findings.time range → line` linkage is required for caption repair
  planning; without it the planner refuses typed (`RepairCauseUnknown`) — that
  refusal is CORRECT behavior, assert it as such.
