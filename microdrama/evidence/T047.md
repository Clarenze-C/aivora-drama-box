   records express the T042b fixture truth, the production reader's windows
   equal `clean_continuity_expectations` on every field except geometry tokens
   (the LocationLayout contract pins a hex sha; the fixture truth carries free
   strings — documented in-test) and handoff presence (the directing contract
   always defines a handoff intent).
2. **Records enter REAL comparison against actual media** — a QA run with the
   production reader and the fixture observer compares identity/outfit cleanly
   (CHECKED coverage, no defect findings, never unknown) and surfaces the
   records-vs-media geometry disagreement as a genuine LOCATION_SPACE finding.
3. **Reader fails closed** — invalidated edit manifest → expectations None
   (unknown, never invented); a tampered wardrobe assignment (fresh row, stale
   hash) loses its outfit dimension AND changes the expectations hash, so no
   cached QA run can survive record changes.
4. **`verify_current_asset` fails closed on every wrong shape** — superseded
   version, wrong hash, absent row, non-ACCEPTED state, and a row whose
   registered sha lies about its stored bytes.
5. **Registry resolver + composed context** — absent subject blocks;
   ELIGIBLE current row resolves; an EXPIRED superseding version kills the
   grant; `load_reference_context` loads the verified record set and its
   `expectations_for` resolves the full semantic reference map (the loader
   gap the test caught — scene locations were missing from the subject set —
   is fixed in the loader).
6. **Intake-born composed release path (T037 closure evidence)** — a season
   created through the three-step wizard (creator-linked at creation) runs
   candidates → Gate 1 → W02–W07 → package → owner metadata manifest (sealed,

queried AssetSheet by `subject_id` and PropSheet/LocationLayout globally, so

`one_sheet` refuse every dispatch. Now: AssetSheet/PropSheet are proven by
`assets.season_id` of their `asset_id` and LocationLayout by
`geometry_sha256` equality with a season-proven location plate — the same
approach as the T044b2 F2 workbench fix. Pinned by
`test_dispatch_context_is_scoped_to_the_episodes_season` (foreign season
seeding shared style/character/prop/location ids; own sheets only; binding
still resolves).

**DB-5 — `_current_doc` fetched one row unordered.** It now requires exactly
one current row per payload key and raises typed
`ambiguous current <Model> records` otherwise (the store permits several
current records to name one payload key — uniqueness is per record_id).
Pinned by `test_current_doc_ambiguity_fails_closed` (two current
SecretLedger records).

**DB-6 — anonymous negative tests.** Every T047 gate refusal now asserts its
own message: asset gates (does-not-exist / not-ACCEPTED / live-version /
row-hash / stored-bytes) and rights gates (no-record / not-eligible /
has-expired / territories-not-covered), each with a version-matched grant so
the intended gate fires. Rights coverage adds the registry's revocation
